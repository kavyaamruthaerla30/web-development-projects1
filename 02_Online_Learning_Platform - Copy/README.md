## Files in each project folder
- `index.html` — readable HTML source code. Open this in Visual Studio Code or view it on GitHub.
- `styles.css` — readable CSS source code. This stylesheet is linked to both HTML pages.
- `output webpage.html` — open this file in Chrome to view the finished, styled webpage.

## How to view and edit
1. Extract the ZIP file.
2. Open the extracted main folder in Visual Studio Code.
3. Open a project folder and edit `index.html` or `styles.css`.
4. To view the final website, double-click `output webpage.html`.
5. Keep all three files in the same project folder so the CSS link works.

**Technology restriction:** HTML5 and CSS3 only. No JavaScript files or JavaScript code are used.

The HTML source is intentionally formatted over multiple lines for readability. `output webpage.html` is a separate copy of the HTML page for convenient opening in Chrome; it uses the same `styles.css` file.
